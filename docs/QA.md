# Win64 release QA (T10)

Date: 2026-11-13. Machine: Windows 11 Home 10.0.26200, 1920×1080 display, NVIDIA GeForce RTX 3060 Laptop (ANGLE D3D11,
GL ES 3.0). Artifact tested: **the zip generated by `tools/package.ps1`** extracted into an empty folder
(`ZombiewoodDev\t10qa`), never the build tree. Game data: the owner's full 1.5.3 APK (306 MB).

How it was tested: **real Windows input** (`keybd_event` with scancodes, `mouse_event`, `SetWindowPos`, `ShowWindow`,
the real Windows file dialog) automated with the scripts in `tools/qa/` (`qa_phase1…5`); window screenshots in
`ZombiewoodDev\t10qa\qa_shots\`, logs in `t10qa\logs\` and each phase's output in `ZombiewoodDev\t10qa_phase*.txt`.
Anything that could not really be exercised is marked **NOT TESTED** (nobody pressing a gamepad, no ears for the audio).

## Startup measurements (win-release, measured in `zombiewood.log`)

- ELF load (35,578 symbols, 364 imports, **552 constructors**): `.init_array` **204–227 ms** (5 runs).
- The game's first `step` (SetupDevice + OBB): **3.9–4.0 s**; then a steady 60 fps (the first 2–3 seconds after the
  first frame have a max `step` of ~100 ms due to texture loading).
- From the start of loading to the first frame: ≈ **5.5 s** with the logo skipped; ≈ 16 s with the full 11-second logo.
- Clean build (vcpkg + FetchContent from scratch, `win-release-T10`): **configure and build without errors**, ctest
  **8/8**. No FetchContent clone hangs (imgui and dynarmic with submodules downloaded on the first try).

## Not tested / known limitations

- Physical gamepad (real presses), real clicks on *Controls/Folders/Help* in the menu and in remapping.
- Audio by ear; playback of the `moviecomplete` video at its real point in the game (requires completing scenes).
- Scenes 2–4 and everything after the shop; store/IAP; languages other than English; `fps_limit`/`vsync` outside their defaults.
- ANGLE Vulkan and D3D9 backends (offered in the menu; only D3D11 and OpenGL were tested in T9).
- Minimize, Alt-Tab and fullscreen **mid-match** (tested in the movie menu; the pause path is the same).
- Other GPUs (AMD/Intel), HiDPI/multi-monitor displays, Windows 10, Windows N without the Media Feature Pack, paths with spaces or Unicode, SmartScreen/antivirus on the unsigned exe.
- Performance measured only on an RTX 3060 Laptop.
